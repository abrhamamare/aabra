# Introductory Web Page

A small HTML learning repository with an `index.html` page and a Hello World example.

## Getting started

Browse the files and commit history to understand this introductory exercise. Open `index.html` in a web browser to view the page.

## What this demonstrates

Basic repository organization and introductory development practice.

## Scope

An educational exercise rather than a production application. No security or test coverage claims are made.
